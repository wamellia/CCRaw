# 水印模板

水印面板使用 semi-utils 模板和处理器，默认选择 `standard2`。启用水印后，预览、单张导出、批量导出及外部编辑交接使用相同配置。水印属于照片调整，可以同步到其他照片，也可以随工程保存。

## 选择布局

`Layout.Type` 提供现行模板与旧版布局。现行模板包括：

| 模板 | 内容 |
| --- | --- |
| standard1 | 标准拍摄参数、机身、镜头、时间与品牌标志 |
| standard2 | 标准水印、圆角、阴影和留白；默认配置 |
| nikon_blur | 尼康机身文字与红色 Z、模糊背景 |
| blur | 机身和拍摄参数、模糊背景 |
| normal1 | 右下角拍摄参数 |
| normal2 | 文件夹名称和时间 |
| center_logo | 居中 Logo 与四周文字 |

旧版布局保留左右 Logo、黑红配色、可定制四角文字、1:1 填充、简洁、背景模糊、模糊加白框以及白色边框等选择。这里的白框来自 semi-utils 的布局，不使用之前的 CCRaw 普通边框渲染器。

## 调整参数

选中处理步骤或文字段后，在属性区调整参数。可添加、删除或移动步骤；合并步骤的输入索引以 0 表示输入照片，1 表示第一个步骤的输出，依此类推。

| 操作 | 参数 |
| --- | --- |
| 文字与文字段 | 内容、字体、高度、颜色、加粗、空白裁切、文字段间距与对齐 |
| 水印排版 | 左上、左下、右上、右下文字，左右及中央 Logo，四边留白、文字间距、分隔线与右侧对齐 |
| 圆角与阴影 | 圆角半径、阴影半径、阴影颜色 |
| 模糊 | 模糊半径 |
| 留白与比例 | 四边留白、颜色、目标宽高比 |
| 缩放与裁切 | 宽度、高度、缩放比例、裁切偏移 |
| 合并与拼接 | 对齐、方向、间距、背景、图层顺序与偏移 |
| 背景生成 | 尺寸、纯色或渐变颜色、渐变方向与插值方式 |

尺寸可使用像素、照片宽度百分比 `vw`、照片高度百分比 `vh` 或表达式。模板中的 `vh`、`vw` 以最终裁切和旋转后的照片尺寸为基准；预览缩小不会改变导出版式。表达式沿用上游形式，例如 `{{vh(2)}}`。

大尺寸照片的实时预览使用屏幕像素网格与超采样，文字和标志仍按最终坐标排版，圆角、阴影及照片模糊按预览网格过滤。完整导出按原分辨率处理；预览中的这些滤镜不会与完整导出逐像素相同。小尺寸照片采用条带过滤，与导出缩小结果一致。关闭或折叠水印面板时不启动新的水印预览任务。

品牌可自动识别或手动选择；导入的 PNG 可用于左侧、右侧或中央 Logo。文字可引用拍摄信息，也可通过元数据覆盖项修改模板使用的值。实际焦距与 35mm 等效焦距独立保留，等效焦距开关决定参数文字采用哪一种。文件夹与文件名来自当前照片，不需要模板自行打开原片。

导入标志作为自动位置的默认资源。处理步骤中显式选择的标志资源优先；选择空资源可以隐藏对应标志。取消属性的自定义勾选则恢复默认行为。

导出文件格式、质量、分辨率、色彩空间及文件名规则沿用导出面板。照片原文件保持不变。旧工程中的普通边框或智能水印配置在读取时转换为模板配置，不再提供原生普通边框选项。

## 来源

现行模板及处理器来自 [semi-utils](https://github.com/leslievan/semi-utils) 的 `b1cf1ce655e9452a78a88f465d4387f84cf6740e`；旧布局参考 `build1521`。CCRaw 接入浮点照片、色彩管理和后台预览，并限制模板图像来源为当前照片、内置资源或用户导入素材。来源与许可见根目录 `THIRD_PARTY.md`。

`nikon_blur` 引用了上游仓库未附带的 `SpecialAlphabets P04 Regular.otf`。该字体选择沿用上游的缺失字体回退；其余内置字体来自上游原文件。文字片段的显式高度覆盖共同高度；未指定时使用模板的共同高度。
