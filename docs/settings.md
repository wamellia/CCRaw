# 系统设置

主界面、Photo Agent 和照片编辑器都有「设置」，快捷键为 Ctrl+,。主题、语言等应用设置同步已经打开的窗口；支持浅色、深灰和跟随 Windows 系统。

| 分类 | 内容 |
|---|---|
| 外观 | 中英文、主题、工作区 |
| 性能 | 自动/CPU、实际设备和回退、渲染/缩略图内存预算、预览尺寸、磁盘缓存 |
| 导入 | RAW/其他图片默认预设、机身规则、作者/版权/关键词默认值 |
| 显示 | 自动显示器 ICC、手动 RGB ICC、渲染意图和黑点补偿 |
| 模型 | 修图指令模型、独立生成服务、本地模型安装与校验 |
| 外部编辑 | 可执行文件及参数，通过独立副本交换 |
| 自动保存 | 配方自动保存、恢复会话、工程备份、恢复提示 |
| 工程 | 代理策略、相册排序等覆盖值 |

应用默认值与工程覆盖分别保存。导入预设和元数据默认值只作用于新照片，不重设已有照片。照片调整保存在配方中。

缓存清理等待活动任务结束，保护仍在使用的文件；原片、代理和模型不作为普通缓存删除。较大的宽色域全图处理在内存不足时提前停止。

「性能 → 任务」集中查看已打开窗口的扫描/工程后台、预览、原像素细节、导出、生成和模型下载。支持取消有取消接口的任务；关闭任务窗口不会停止工作。近期结束记录只保留在本次任务窗口内；生成历史与工程执行记录继续保存在各自工作流中，不会自动重试请求。

自动保存记录配方、快照及恢复信息，不自动导出照片或写入原片。异常退出后从「自动保存」恢复会话；切换照片和正常关闭前完成待保存状态。

分享设置不包含 API Key、提示词或照片事实。密钥继续使用 Windows DPAPI 存储，模型与缓存位于用户数据目录。

外部生成执行前仍需检查 Provider、上传内容和费用，设置不能绕过该确认。模型缺失时基础编辑与管理仍可使用，界面显示 AI 能力的实际可用性。
