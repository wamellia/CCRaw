# 系统设置

主界面、Photo Agent 和照片编辑器都有「设置」，快捷键为 Ctrl+,。主题、语言等应用设置同步已经打开的窗口；支持浅色、深灰和跟随 Windows 系统。

| 分类 | 内容 |
|---|---|
| 工作区 | 常规、外观与语言、工程偏好 |
| 照片与色彩 | 导入默认风格、机身规则、默认元数据、显示器 ICC 与色彩 |
| 性能与存储 | 计算、预览与缓存、维护与诊断 |
| AI 与服务 | 对话与修图、图像生成、语音、本地模型 |
| 工作流 | 外部编辑程序、参数与交换格式 |
| 保存与恢复 | 自动保存、工程备份、会话恢复 |

左侧目录按两级分类导航，右侧表单按用途分组。应用默认值与工程覆盖分别保存；选择工程覆盖时，目录只显示该工程可设置的导入与工程偏好。导入预设和元数据默认值只作用于新照片，不重设已有照片。照片调整保存在配方中。

缓存清理等待活动任务结束，保护仍在使用的文件；原片、代理和模型不作为普通缓存删除。较大的宽色域全图处理在内存不足时提前停止。

「性能与存储 → 计算」显示检测到的 GPU 型号、专用显存、驱动、可用 ONNX 后端，以及最近实际执行的 GPU 步骤。编辑器的「自动加速」下方也显示设备与执行路径；检测到 GPU 不代表所有步骤都由 GPU 计算。未运行滤镜时显示当前 CPU 或待验证的 ONNX 路径，实际运行后更新为 OpenCL / DirectML / CUDA 与 CPU 的组合。

自动模式会为适合的大图合并清晰度、纹理与锐化，保持中间结果在 OpenCL 设备上；大半径单通道高斯滤镜也可自动加速。小图、缓存命中、超出设备预算或不支持的操作继续使用 CPU；设备运行失败时回退 CPU。OpenCL 在后台处理线程首次需要时初始化，设置页面读取缓存状态。手动 CPU 选项关闭照片渲染的自动 GPU 路径；AI 模型设备仍由各自模型配置决定。

「性能与存储 → 维护与诊断 → 任务」集中查看已打开窗口的扫描/工程后台、预览、原像素细节、导出、生成和模型下载。支持取消有取消接口的任务；关闭任务窗口不会停止工作。近期结束记录只保留在本次任务窗口内；生成历史与工程执行记录继续保存在各自工作流中，不会自动重试请求。

自动保存记录配方、快照及恢复信息，不自动导出照片或写入原片。异常退出后从「保存与恢复 → 会话恢复」恢复会话；切换照片和正常关闭前完成待保存状态。

分享设置不包含 API Key、提示词或照片事实。密钥继续使用 Windows DPAPI 存储，模型与缓存位于用户数据目录。

外部生成执行前仍需检查 Provider、上传内容和费用，设置不能绕过该确认。模型缺失时基础编辑与管理仍可使用，界面显示 AI 能力的实际可用性。
