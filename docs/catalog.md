# 选片与相册管理

Photo Agent 工程直接显示管理工具。快捷编辑从底部「管理相册」打开同一套管理界面；传统 `.ccrawalbum` 仍可保存和打开。管理操作记录在工程中，不自动删除或改写原片。

左侧导航按照片状态、相册与文件夹、常用筛选组织；中间显示照片、排序和选片控制，右侧保留 Agent 对话。导入照片与文件夹共用「导入」菜单。选中照片后显示编辑、标注、推荐及更多操作。

「图库管理」按相册与筛选、选中照片、原片/代理/回收站、历史与备份四组提供操作。操作随选择数量和任务状态启用；右键菜单使用同一组动作。

## 选片

选中照片后使用 0–5 评级、保留/拒绝/未标记及颜色标签。快捷键为数字 0–5、P/X/U；方向键连续浏览，「自动前进」控制评级后是否切到下一张。输入框获得焦点时这些按键用于输入文字。

「比较」显示两张照片，可同步缩放和平移，使用原像素区域检查；「多图筛选」临时剔除候选，不移除工程照片。评级、标记和管理历史可撤销/重做，AI 质量评分与用户评级分别保存。

## 组织和查找

| 功能 | 使用方式 |
|---|---|
| 相册和文件夹 | 普通相册、多级文件夹、目标相册、快速集合；照片可加入多个相册，删除相册不删除原片 |
| 智能相册 | 根据评级、标记、日期、机身、镜头、ISO、格式、关键词和编辑状态动态查询 |
| 筛选和排序 | 组合条件，按日期、名称、评级或导入顺序排序；语义结果可继续筛选 |
| 常用筛选 | 保存、更新、删除命名筛选，或从当前条件创建智能相册 |
| 堆栈 | 手动/按时间分组、封面、折叠/展开；查看连拍清晰度与曝光建议 |
| 虚拟副本 | 共享原片，独立配方和历史；分别在编辑器或 Agent 中调整 |
| 人物簇 | 匿名候选支持合并、拆分和移除误识别；不要求上传或填写真实姓名 |

高级筛选的 all/any/none 规则可嵌套，字段和操作符受限，不接受任意 SQL。照片列表稳定分页，扫描与建议分批覆盖工程，不将单次 10,000 张照片或 3,000 张人脸作为总量上限。语义和人物能力需要本地模型。

重复、相似、质量和事件建议可以保留、忽略或标记已处理，重新打开工程后保留状态。推荐编辑方案只显示当前选中照片，应用结果保存为派生版本。

## 照片信息和离线工作

「照片信息」支持标题、说明、作者、版权、地点和层级关键词。多选显示混合值，只有勾选的字段才批量写入工程；关键词可追加、替换或移除。使用 XMP/导出才把信息写入旁车或输出文件。

「图库管理 → 原片、代理与回收站」可查看缺失照片、指定新位置、搜索候选和批量重定位文件夹。优先校验原片 hash，保持照片 ID、相册引用和编辑历史。

可为选中照片生成、迁移和清理离线代理。代理为带指纹的 16 位 TIFF，原片离线时可继续编辑；恢复原片后使用原片导出。原片缺失会阻止全尺寸导出，只有明确选择代理输出才允许输出代理。

工程回收站提供移除、恢复和清空记录，默认不删除磁盘文件。清空管理记录前备份 SQLite 数据库；清理代理不会清理原片或模型。
