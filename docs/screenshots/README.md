# 界面演示图片 / Screenshot samples

本目录的产品界面截图由实际 CCRaw 控件及 Photo Engine 渲染生成。

编辑流程截图使用维护者提供并指定用于功能展示的五份 Nikon NEF 样片和天鹅照片。编辑器展示 NEF 原片及 JPEG；图库和 Agent 展示同组照片经 Photo Engine 导出的 JPEG 演示副本，实际执行了本地扫描、评级、相册整理、语义查询、推荐和方案预览。

图像生成截图展示以当前照片准备任务的界面。这些截图未调用外部生图服务。不同示例的参数用于说明操作，不代表唯一推荐的处理方式或效果保证。

仓库包含的是界面截图。原始照片、独立演示 JPEG、工程、模型与缓存保留在本地，不随这些截图分发。源码的 MIT 许可不构成对底层摄影作品的独立许可授予。

These product screenshots were captured from actual CCRaw widgets and Photo Engine output. The workflow screenshots use five Nikon NEF files and a swan photograph supplied for documentation. Editor screenshots show the source photographs; catalog and Agent screenshots use JPEG demonstration copies exported from the same images through Photo Engine, with real local scanning, ratings, albums, semantic retrieval, recommendations and proposal previews.

The generation screenshot shows task preparation with the current photograph. No external generation request was made for these captures. Example adjustments illustrate workflows rather than guaranteed or uniquely recommended results.
