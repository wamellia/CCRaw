# 专业编辑

照片编辑器右侧按光影、色彩、细节、构图、局部、效果六个栏目组织工具。同一栏目中的参数按可折叠分组展示，专业参数与常用工具放在一起。这些参数在拖动时更新预览，保存在照片配方中，可撤销、同步及导出。原片不变。

| 栏目 | 分组 |
|---|---|
| 光影 | 曝光与明暗、曝光曲线、RGB 与通道曲线 |
| 色彩 | 白平衡、全局色彩与 HSL、色彩分级、黑白混色、点颜色、相机校准、配置文件与显影空间 |
| 细节 | 质感、常规降噪、精细锐化与降噪、AI 细节处理 |
| 构图 | 裁切与旋转、镜头与光学校正、透视与几何 |
| 局部 | 蒙版、修复与仿制、红眼修复 |
| 效果 | 暗角、胶片颗粒、水印与边框 |

「重置当前分组」仅恢复当前展开分组的参数。旁边的下拉箭头提供「重置所有调整」，也可从「照片 → 调整 → 重置所有调整」进入；两种重置均支持撤销。

预览请求以最高 60 Hz 调度，持续拖动只保留最新待计算参数，不累积过期帧。拖动期间保留预览分辨率；100% 视图计算当前可见的原片区域。处理器、图像尺寸、宽色域转换、多个滤波和局部调整会影响实际帧率，调度频率不等于每种操作都达到 60 fps。

组合蒙版中的不透明度、羽化、位置、反选以及组件添加、删除和排序会立即更新照片。确认后保存为一次撤销操作，取消会恢复打开弹窗前的配方。

## 显影和颜色

「兼容显影 · sRGB」保留旧工程的外观；「宽色域显影 · Rec.2020」使用浮点工作空间，保留输入中超出 sRGB 的颜色和中间步骤的负值、高光。16 位 TIFF/PNG 和支持的 PSD 输入不会先降为 8 位。RAW 通过 LibRaw 解码，已在解码阶段截断的数据不能恢复。

导出可选择 sRGB、Adobe RGB、Display P3、ProPhoto RGB 或 Rec.2020，并写入对应 ICC。JPEG 为 8 位；TIFF、PNG 和合并 RGB PSD 可选 8/16 位。屏幕预览受显示器和 SDR 显示范围限制，不代表 HDR 显示输出。

「设置 → 照片与色彩 → 显示与色彩」可使用 Windows 当前显示器 ICC，或指定 RGB 显示配置文件。导出对话框中的「软打样」可选择输出 ICC、渲染意图、黑点补偿、纸墨模拟和色域预警。打样与显示器转换只影响显示，不改变配方和导出像素。

## 工具

| 页面 | 操作 |
|---|---|
| 光学 | 手动畸变、光学暗角、红/蓝横向色差、紫绿边抑制；导入本地 Lensfun XML 后选择镜头和焦距 |
| 几何 | 水平/垂直透视、缩放、纵横变形、偏移和翻转；「约束裁切到有效图像」计算校正后的可用矩形 |
| 校准 | 阴影色调、红绿蓝原色色相与饱和度 |
| 细节 | 锐化量/半径/细节/遮罩、亮度降噪细节与对比、颜色降噪细节与平滑；100% 检查可见原像素 |
| 黑白 | 八色混色；自动黑白起点；启用目标调整后在照片上上下拖动对应色带 |
| 点颜色 | 最多 16 个原片颜色样本；分别调整色相、饱和度、明度、范围和羽化；显示当前选区 |
| 配置 | 导入 `.cube`、RGB ICC 或 DCP，调整强度；DCP 可选自动、仅外观或 RAW 相机校色 |
| 红眼 | 标记瞳孔中心，调整半径与压暗量；每个瞳孔可单独移除 |

Lensfun 导入支持 poly3、poly5 和 PTLens 畸变标定，使用导入文件保存的校正数据；未匹配的镜头继续使用手动校正。软件不附带镜头数据库，不将 XML 中未支持的色差/暗角标定当作已应用。

DCP 支持标准双光源矩阵、ForwardMatrix、色表、外观表、色调曲线及基准曝光。RAW 相机校色需要原始相机 RGB；普通图像可应用 DCP 外观。私有标签及部分扩展不会产生与 Adobe 软件完全相同的结果，导入时显示支持范围。配置文件作为外部资源引用，应随工程保留；移动文件后需重新指定。

## 局部处理和复用

蒙版页「添加 / 减去 / 交集…」可组合现有几何、画笔、颜色、亮度范围和 AI 蒙版，调整顺序、反相和透明度。父蒙版透明度作用于整个组合结果；画笔可补充或擦除。自动选区依赖相应本地模型。

Photo Agent 的方案预览可加载原像素双图比较，以相同的 Photo Engine 分别渲染当前配方与建议配方。两图同步缩放和移动，不应用方案，也不生成派生文件。

选片集中的「同步调整」提供参数组选择。默认保留目标照片的白平衡相机基准、裁切、几何、蒙版、修复和水印；需要时显式选择这些组。每张照片维护自己的配方和历史。

## 输出与交换

导出可保存预设，配置命名、冲突处理、分辨率、尺寸、位深、色域、输出锐化及元数据策略。移除 GPS 或仅保留版权不会改写原文件。

外部编辑使用独立 TIFF/PSD 副本，按配置的可执行文件和参数启动；回传作为新版本导入，保留来源。PSD 是合并 RGB 图像，不生成图层、智能对象或 PSB。

XMP 读取/写入标准元数据及支持的编辑字段，保留未知命名空间，并保存 CCRaw 完整配方。其他编辑器的算法和字段并不完全一致，跨软件不能保证逐像素外观相同。
