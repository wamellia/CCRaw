# Photo Agent

CCRaw 的照片编辑和 Photo Agent 共用 Photo Engine。传统 `.ccraw` 和 `.ccrawalbum` 格式保持兼容；Agent 工程使用 `.ccrawagent`，一个工程对应一个独立相册、会话与执行记录。

## 开始

1. 安装 `requirements-agent.txt`，使用 `main.py` 启动。
2. 选择 Photo Agent，新建工程或打开现有工程。
3. 在「模型设置」选择支持工具调用的模型。该配置与照片编辑器的修图指令共用，API Key 使用 Windows DPAPI 保存。
4. 点击「本地模型」下载校验后的 CLIP、YuNet 和 SFace，或运行 `python tools/agent_models.py`。这一步只下载模型，不上传照片。
5. 导入照片或文件夹。先完成本地扫描，再在模型已配置时启动整理对话。

## 查询与编辑

聊天可以输入「整理当前工程」「找到去年夏天海边的日落」「对选中照片推荐自然增强方案」「让选中照片再暖一点」。找图结果会显示在照片区；点击整理建议可查看对应照片。

照片缩略图按原比例居中完整显示，文件名和像素尺寸独立排列。照片区随窗口宽度调整列数；拖动照片区与下方建议面板之间的分隔条，可调整两部分的高度。

工具中的日期范围为开始日期包含、结束日期不包含。人数条件以人工标注为准，未知人数默认作为明确标注的候选；请求 `strict_people=true` 时排除未知人数。匿名人物簇可用 `person-…` 编号检索，编号不代表真实身份。标签通过选中照片后的「标注人数 / 标签」保存。

「推荐修图」无需 LLM。选择方案、确认参数后，Photo Engine 从原片全分辨率计算并输出 16 位 TIFF 派生版本。双击照片或点击「照片编辑」进入完整编辑器；完成调整后点击菜单「保存调整到 Photo Agent」，把配方保存回工程，再继续推荐、生成或导出。

外部编辑使用图像生成设置，和对话服务分开配置。聊天工具只准备方案。确认窗口展示实际服务地址、模型、图片尺寸和字节数、提示词及费用；未知费用明确显示未知，不估造价格。当前发送的是最大边 2048 像素、不含 EXIF 的处理后 JPEG 和提示词。确认绑定当时的服务配置、原片与参考图校验值，变化后需要重新创建方案。提交后取消可能仍产生服务商费用。外部图像按服务返回的尺寸与编码保存。

## 本地数据

工程旁的 `.ccrawagent-data` 包含 `project.sqlite3`、`previews`、`derived`、`agent` 和 `sessions`。SQLite 保存照片事实、偏好、会话、事件、任务、方案与派生版本来源；`agent` 为运行工作区，`sessions` 保存 nanobot 会话，二者都在工程数据目录内。移动工程时应一起移动清单与数据文件夹；原片仍按路径引用，原片移动后需要重新导入。

模型位于 `%LOCALAPPDATA%/CCRaw/agent-models`。`CCRAW_AGENT_MODEL_DIR` 可指定模型目录。五个文件的固定下载位置、大小与 SHA-256 位于 `ccraw/resources/agent-models.json`，安装失败不会替换有效模型。CLI 使用 `python tools/agent_models.py --verify-only` 检查资源。

原片不会被整理建议删除或覆盖。重启将未完成任务标记为中断；执行记录只供回看，不自动重发外部请求。工程事实、会话及用户偏好分开保存，聊天上下文只包含有限的当前工程信息。

## 范围

单工程上限 100000 张。扫描和查询按页读取；照片区每页显示 200 张，查询最多返回 100 张。一次整理建议覆盖前 10000 张已导入记录中的有效照片，人脸聚类最多处理其中 3000 个人脸，界面和报告显示覆盖量。重复组依据 SHA-256；相似组依据感知哈希、颜色和画幅比例，质量和事件均需要人工判断。人物聚类可能合并或拆分错误，不用于身份识别。

本地 CLIP 使用固定版本 ViT-B/32 的量化 ONNX，主要适合英文语义。直接找图内置少量中文词映射；复杂中文、时间表达及组合条件通过 LLM 生成受约束查询。无模型时退化为文件名、标签及元数据检索，不伪装成语义识别。Agent 的参数工具覆盖全局调色、曲线、HSL、色彩分级与效果；自动选区、修复、堆栈等完整工作流通过照片编辑器完成。

没有后台持续联网或无人值守付费功能；导入、扫描及每条指令构成一次有限任务。LLM 循环最多 8 轮工具调用，上下文预算为 16384 token，普通回复最多 2048 token，对话时间受模型设置中的超时约束。本地模型服务建议配置至少 16K 上下文。取消将在安全边界生效，单次原片解码和推理完成前可能需要等待。
