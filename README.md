# CCRaw-Pro v1.2

简体中文 | [English](README.en.md)

**面向 Windows 的开源专业照片编辑与 Photo Agent 软件。**

v1.2 围绕编辑效率、模板水印和自动 GPU 加速升级：专业编辑按光影、色彩、细节、构图、局部和效果分组；设置采用两级目录；模板水印提供完整的可视化布局调节，默认使用 standard2；自动模式按图像与缓存状态选择计算路径，并显示 GPU 信息。发布名称为 **CCRaw-Pro v1.2**，软件版本为 **1.2.0**。浮点宽色域显影、选片与相册管理、Photo Agent 和图像生成继续保留。

CCRaw 将照片调整、局部编辑、选片管理和 AI 图像创作放在同一个工作空间。导入原片后，可以实时调整光影与色彩、比较编辑效果、保存工程，再将成片单独导出。原片保持不变，调整可撤销，也可保存为预设应用到其他照片。

![CCRaw 深色编辑界面](docs/screenshots/editor-dark.webp)

## 两种工作空间

启动页左侧提供「Photo Agent 新建工程」「打开 Agent 工程」和「快捷编辑」。右侧按最近打开时间展示 Agent 工程，可按名称或路径搜索，单击即可继续工作。快捷编辑保留原有 RAW 调整、选片集、实时预览、蒙版、裁切、指令与生成工作流。Photo Agent 以一个工程管理一组照片，通过本地分析与模型对话完成整理、检索和编辑方案选择。

![CCRaw 工作空间入口](docs/screenshots/workspaces.webp)

主界面、Photo Agent 和照片编辑器均提供「外观」和「设置」入口，可选择浅色、深灰或跟随系统，以及切换中英文。设置快捷键为 Ctrl+,，修改同步已经打开的窗口。

### Photo Agent

新建 `.ccrawagent` 工程，导入照片或文件夹，即可开始扫描。工程记录原片引用，分析结果、会话和派生版本保存在旁边的 `.ccrawagent-data` 文件夹中。

| 工作 | 结果 |
|---|---|
| 整理 | SHA-256 完全重复组、相似候选、曝光与清晰度提示、按拍摄时间形成的事件、匿名人物簇 |
| 找图 | 将自然语言转为限定条件，组合拍摄日期、文件名、标签、本地 CLIP 向量、人物簇和质量信号 |
| 修图 | 选中照片后先本地诊断，每张最多三种方案；支持自然语言调色、裁切、旋转、曲线及几何蒙版，应用前可查看前后预览 |
| 多选调整 | 为 1–30 张选中照片创建方案，保留各自未改动的参数；逐张预览并确认 |
| 继续编辑 | 直接打开现有照片编辑器，使用完整工具，并将参数保存回 Agent 工程 |
| 外部编辑 | 执行前查看 Provider、模型、上传图片、提示词和费用；结果保存为独立派生版本 |
| 执行记录 | 会话、任务和工具调用持久保存；查看历史不会重新执行请求 |

![CCRaw Photo Agent 工作区](docs/screenshots/photo-agent.webp)

Agent 默认复用「修图指令」的模型配置，无需维护第二套对话 API Key。对话服务需要支持工具调用；对话只发送指令、有限工程摘要和工具结果，图像分析在本地进行。

没有配置 LLM 时仍可扫描、查看整理建议、使用本地找图和推荐修图。本地语义检索与匿名人物聚类需要从「设置 → AI 与服务 → 本地模型」安装约 186 MiB 的校验模型；模型文件与源码分开保存。

人物检测和聚类属于候选信号。画面人数默认未知，可通过「标注人数 / 标签」核验；严格人数查询排除未知照片。事件依据 EXIF 拍摄时间，缺失时不使用文件修改时间代替。复杂中文找图建议使用 Agent 对话，由模型转成检索条件与英文语义查询。功能边界及工程存储见 [Photo Agent 使用说明](docs/photo-agent.md)。

选中方案后点击「预览方案」，并排查看当前调整与方案效果；预览不生成派生版本。可以输入「把选中的照片曝光设为 0.3 档，保留各自裁切」，或「裁切选中照片右半部分，先预览」。参数工具会检查名称、数值范围和坐标，无法执行的参数会明确报错。

![CCRaw Agent 方案前后预览](docs/screenshots/agent-preview.webp)

支持工具调用的外部 Agent 可通过标准 stdio MCP 接入同一套照片工具，查询参数、检索工程、创建方案并取得前后预览图。MCP 使用 Python 源码启动，编辑目标通过照片 ID 明确指定；派生版本仍在软件中确认后生成。连接方式和参数示例见 [Agent 工具与 MCP](docs/agent-tools.md)。

## 从原片到成片

### 拖动即预览

拖动滑杆、编辑曲线或转动色彩分级色轮时，画面随参数变化更新。适应窗口时查看整体效果，切换到 100% 查看可见区域的原图像素；使用「原片」和「前后对比」检查每一步调整。

图像计算与界面交互分开执行，连续输入会合并处理。自动加速按图像大小、工具组合和缓存状态选择计算路径；支持 OpenCL 邻域滤镜，以及可选的 DirectML、CUDA 像素计算和模型推理。编辑器显示 GPU 型号、专用显存和实际使用的路径。实际响应速度取决于照片尺寸、调整类型和设备配置。

专业工具和组合蒙版支持修改时预览；确认组合蒙版后可一次撤销，取消则恢复原状态。预览以最高 60 Hz 调度，拖动时保留当前预览分辨率，100% 视图更新可见区域的原片像素。实际图像刷新率由处理耗时决定。照片解码、曲线插值、滤波和颜色阶段会复用缓存，以减少重复计算和等待。

### 常用编辑工具集中呈现

| 工具 | 能做什么 |
|---|---|
| 光影 | 曝光、对比度、暗部与亮部、黑白场和曲线调整 |
| 色彩 | 白平衡、HSL 和色彩分级，控制整体色调与局部颜色 |
| 细节 | 锐化、降噪与可选 AI 细节处理 |
| 构图 | 裁切、旋转、镜头和透视校正；框内拖动保持尺寸，移动取景 |
| 局部 | 蒙版、画笔、渐变、自动选区、修复与红眼 |
| 效果 | 暗角、胶片颗粒、模板水印与留白 |

裁切框画好后，可在框内自由移动；在框外拖动可重新划框。点击「确认裁切」或按 Enter 应用。

水印采用 semi-utils 的模板与处理器组合，默认 `standard2`，包含圆角、阴影、留白和拍摄参数。可选择七套现行模板及旧版 `Layout.Type` 布局，调整文字、字体、颜色、Logo、边距、对齐、模糊与阴影等设置。原生普通边框已由模板水印替代；旧工程配置在读取时迁移。

水印预览、单张和批量导出共用同一处理流程。模板按照片的最终尺寸确定布局，预览缩小显示；照片内容保留浮点精度。详细设置见 [水印模板](docs/watermark.md)。

### 保存编辑，复用风格

工程保存为 `.ccraw`，选片集保存为 `.ccrawalbum`，预设保存为 `.ccrawpreset`。使用快照保留不同调整方案，再用预设和同步调整统一一组照片的风格。

### 专业编辑与完整相册工作流

编辑器按光影、色彩、细节、构图、局部、效果六类组织工具，专业参数并入对应栏目，以可折叠分组展示。镜头校正、透视与翻转位于构图；RGB 校准、八色黑白混色、点颜色和 LUT/ICC/DCP 位于色彩；精细降噪与锐化位于细节；红眼位于局部。点颜色可显示选区；黑白支持在照片上拖动调整色带；组合蒙版和同步调整可按分组操作。

宽色域显影使用浮点 Rec.2020，支持五种输出色域和对应 ICC，以及 16 位 TIFF/PNG/合并 RGB PSD。显示器 ICC、软打样和色域预警与输出分开。导出预设、元数据策略、输出锐化、外部编辑副本及 XMP 集中在导出工作流中。支持范围见 [专业编辑](docs/editing.md)。

Photo Agent 和快捷编辑中的「管理相册」共用评级、标记、颜色标签、多相册、文件夹、智能相册、常用筛选、比较、多图筛选、堆栈及虚拟副本。还可批量编辑元数据、修正匿名人物簇、重关联原片、管理代理及回收站。见 [相册管理](docs/catalog.md)。

统一设置管理性能、缓存、导入规则、服务和自动保存，支持异常恢复；分享配置不包含密钥。见 [系统设置](docs/settings.md)。

## 用文字调整和创作

「指令」包含修图与生成两种工作流程。自然语言修图可连接本地模型或云端服务，将描述转为可继续编辑的参数；可选 SenseVoice 模型在本地识别语音。

### 三种图像生成方式

| 模式 | 使用方式 |
|---|---|
| 创意模板生成 | 从 50 个内置主题出发，创作贴纸、拍照亭、微缩模型、漫画、蓝图等图像 |
| 风格化生成 | 从 31 种风格中选择摄影、动漫、绘画、像素、艺术家风格等效果 |
| 自定义生成 | 直接输入自己的提示词，自由设置参考图与生成参数 |

![CCRaw 图像生成面板](docs/screenshots/generation.webp)

模板支持分类、搜索和效果预览。选中主题后可以继续修改提示词，或保存自己的模板；「清空」重置当前模式的模板选择和提示词。超写实壁纸模板会先让你选择拍摄主体。

![CCRaw 风格化主题浏览器](docs/screenshots/templates.webp)

![CCRaw 创意模板浏览器](docs/screenshots/creative-templates.webp)

主题图片用于展示风格方向，实际生成结果取决于参考图、提示词和所配置的模型。

### 参考图、队列与生成记录

生成支持文生图和图生图。可以选择当前照片作为参考，也可以只使用提示词；每张参考图可生成 1–4 张，队列最多 32 张。结果独立保存，可打开继续编辑或另存为，生成记录可在下次启动后查看。

在生成面板的「设置」中填写 Seedream 或兼容图像生成服务的接口地址、模型和 API Key。生成配置与修图模型分开保存。只有勾选「发送参考图」时才发送经过处理的参考图片；基础照片编辑无需云端服务。服务商可能按请求计费，取消已提交的请求不一定停止服务端处理。

## 开始使用

CCRaw 当前及后续发行面向 **Windows 64 位**。源码运行推荐使用 **Python 3.12 64 位**。

在项目目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

依赖安装后，也可运行 `run-source.cmd`。已经配置好开发环境时，直接执行启动命令即可，无需重新创建环境。

使用 Photo Agent 对话与语义模型，再安装可选依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-agent.txt
```

1. 选择「快捷编辑」，点击「打开」导入 RAW 或常见照片文件；或新建 Photo Agent 工程后导入照片。
2. 在右侧选择光影、色彩、蒙版、裁切等工具，实时查看调整效果。
3. 保存工程，或点击「导出」生成成片。
4. 需要文字修图或图像生成时，进入左侧「指令」并配置对应服务。

### 可选运行资源

Git 仓库和 Python 包包含界面、字体与主题预览图；大型 AI 模型和 ExifTool 通过独立资源包提供。基础编辑可以先使用，启用相关模型功能时再安装资源。

从 [运行资源下载页](https://github.com/wamellia/CCRaw/releases/tag/runtime-assets) 下载 `CCRaw-0.1.0-RuntimeAssets.zip`，在项目目录执行：

```powershell
.\.venv\Scripts\python.exe tools/fetch_assets.py --archive "C:\path\CCRaw-0.1.0-RuntimeAssets.zip"
```

将示例路径替换为实际下载位置。完整离线交付目录已包含运行资源时，无需重复安装。模型用途与许可见 [模型资源说明](MODEL.md)。

### 可选 GPU 加速

默认依赖提供 CPU 运行环境；驱动和 OpenCV 支持 OpenCL 时，自动模式还可加速适合的邻域滤镜，无需安装 CUDA 包。清晰度、纹理和锐化可合并执行，减少设备传输；小图和已有缓存优先沿用 CPU 快速路径。手动选择 CPU 可关闭照片处理的自动 GPU 路径。设备信息与执行详情见「设置 → 性能与存储 → 计算」。

Windows GPU 环境可选择 `requirements-directml.txt`，NVIDIA CUDA 环境可选择 `requirements-gpu.txt`，启用额外的 ONNX 加速。安装前按相应文件中的说明移除其他 ONNX Runtime 发行包，每个环境只保留一种；具体驱动与系统要求见依赖文件和 [构建说明](docs/releasing.md)。

## 数据与开源

照片编辑在本地完成，CCRaw 不会自动上传照片、日志或遥测数据。自然语言和图像生成按你配置的服务发送请求，API Key 使用 Windows DPAPI 保护，并与源码分开保存。详情见 [隐私说明](docs/privacy.md)。
